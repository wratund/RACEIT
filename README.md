  RaceIt Desktop Client

The desktop client for RaceIt. Play matches without keeping a browser tab open. 

  Installation:
1. Go to the **Releases** section on the right side of this page.
2. Download the latest "RACEIT-setup.exe".
3. Run the installer and follow the on-screen instructions.

 Note:
Since this is a new app, Windows might show a security warning. Just click **"More info"** and then **"Run anyway"**.
